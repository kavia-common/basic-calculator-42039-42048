Ocean Professional Calculator

- UI: Central panel with rounded corners, subtle shadows, and gradient backdrop.
- Theme Colors: primary #2563EB, secondary #F59E0B, error #EF4444, text #111827, surfaces #ffffff on background #f9fafb.
- Features:
  - Buttons: 0–9, ., +, -, ×, ÷, =, C, CE, %, +/-
  - Mouse input and keyboard: digits, + - * /, Enter/=, Backspace, Escape, %
  - Operations: add, subtract, multiply, divide, percentage, toggle sign, clear entry (CE), clear all (C)
  - Display shows current entry and previous operand+operator
- Logic utilities are in src/lib/calcUtils.ts to keep component clean.
